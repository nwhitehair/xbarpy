## XBarPy

_XBarPy_ is a work-in-progress Python package to support working with [X-bar structures](https://en.wikipedia.org/wiki/X-bar_theory).
The intent is to provide a framework that allows for going between linear-text and X-bar representations of natural-language phrases.
The project is motivated by a desire to explore relationships between modern language modeling (especially transformers) and established theoretical linguistics.
